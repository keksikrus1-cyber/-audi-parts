# Design Reference

## HTML Макет

Путь: `docs/design/audi-parts-reference.html`

Этот файл — **единственный источник правды** для визуального дизайна AudiParts. Все UI-решения принимаются на основе этого макета.

## Дизайн-система

- **Цвета**: CSS-переменные в `:root` и `[data-theme="light"]`
- **Акцент**: `#d0a84a` (золотой)
- **Фон dark**: `#0a0a0f`, `#111118`, `#16161f`
- **Шрифты**: IBM Plex Sans, Rajdhani, IBM Plex Mono
- **Радиус**: `12px` (переменная `--radius`)
- **Переходы**: `0.2s ease`

## Правила сохранения дизайна

1. **Не менять** цвета, отступы, радиусы, типографику без явного разрешения.
2. **Не придумывать** новые компоненты — сначала проверить, есть ли аналог в макете.
3. **Не заменять** сетку и общую атмосферу.
4. При переносе в React — точно воспроизводить HTML/CSS из макета.
5. Если чего-то не хватает в макете — предложить план, не реализовывать самостоятельно.

## Порядок переноса дизайна в React

1. Перенести CSS-переменные и базовые стили в глобальный CSS.
2. Создать компоненты по карте `UI_COMPONENT_MAP.md`.
3. Сначала — статичные компоненты с mock-данными.
4. Потом — подключение к реальному API.
5. Каждый компонент сверять с HTML-макетом визуально.
